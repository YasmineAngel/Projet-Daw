# E-commerce Project

This project is an old university assignment for the course Web Application Development.

It is a basic e-commerce-style web application built as a learning exercise to practice the fundamentals of web development using HTML, CSS, and JavaScript. The project demonstrates how to structure a simple front-end website, create product pages, handle navigation, forms, and interactive UI elements, and organize a small online shopping experience.

## Project purpose

The goal of this project was to apply the basics of:

- HTML for page structure and content
- CSS for layout, styling, and responsiveness
- JavaScript for interactivity and client-side behavior
- Basic web design concepts and user experience
- Simple e-commerce page flow such as product listing and ordering

## Project overview

This project includes:

- Landing page and homepage
- Product listing and product detail pages
- Shopping/order-related pages
- Registration and login pages
- Styling with CSS files and assets
- JavaScript-based interactions and validation

## Technologies used

- HTML
- CSS
- JavaScript
- jQuery
- PHP for some form and backend-related logic

## Notes

This is an older academic project, created for learning and practice rather than production-level development. It reflects the early stage of web development learning, especially the basics of front-end application creation and simple dynamic behaviors.

## How to run

Open the main HTML file in a browser, such as:

- index.html

If the project depends on a local server for PHP-related pages, run it using a PHP-enabled local environment such as XAMPP or WAMP.
